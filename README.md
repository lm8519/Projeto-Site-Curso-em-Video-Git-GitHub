# Projeto Site - Curso em Vídeo (Git e GitHub)
Este repositório contém um projeto desenvolvido durante o curso **Git e GitHub**, do **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.
O objetivo é colocar em prática os principais conceitos de versionamento com Git e GitHub, acompanhando as aulas e registrando minha evolução ao longo do curso.

## Objetivos
- Aprender os fundamentos do Git e do GitHub.
- Criar e gerenciar repositórios.
- Trabalhar com branches.
- Realizar commits e merges.
- Publicar projetos no GitHub.
- Hospedar um site utilizando o **GitHub Pages**.

## Tecnologias utilizadas
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Visual Studio Code

## Funcionalidades praticadas
- Criação de repositório
- Versionamento de arquivos
- Commits
- Branches
- Merge
- Push e Pull
- Organização do projeto
- Publicação com GitHub Pages *(em andamento)*

## Como executar
1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em qualquer navegador.
